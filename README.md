## Current canon and development notes

This is a living story document. Established decisions are recorded as canon; details that have not yet been decided are marked **TBD**. Do not treat TBD material as confirmed lore.

The game is planned as a single-player survival-horror experience set in an abandoned psychiatric hospital. The current target is approximately 1–1.5 hours for the main story. The first development target is PC, with Android also considered.
