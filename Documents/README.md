This folder is an index for documents that may appear as collectible story material in Hollow Ward. These are document concepts; full text and exact placement are still to be written.

## Document-writing rules

1. Each document should reveal one or two useful clues.
2. The writing voice should match its author: clinical, bureaucratic, frightened, or personal.
3. Documents should not reveal protected twists too early.
4. Conflicting records may be used intentionally, but the underlying canon must remain consistent.
5. Dates, names, signatures, and room numbers should be tracked once finalized.
